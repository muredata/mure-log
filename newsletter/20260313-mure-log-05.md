## Data Reads

**01 / [Your Pipeline Succeeded. Your Data Didn't](https://robertsahlin.substack.com/p/your-pipeline-succeeded-your-data)** - Robert Sahlin
Pipelines report success while delivering corrupted data silently. Nordnet implemented anomaly detection using liveness scores and maximum gap analysis to catch partial data drops before business impact occurs. "Data quality != pipeline success."

**02 / [Why I (Still) Use Aider in 2026: Code Ownership, OpenSpec, and the Vibecoding Hype](https://semyonsinchenko.github.io/ssinchenko/post/aider_2026_and_other_topics/)** - Sem Sinchenko
Vibecoding generates high volume but destroys code ownership through reviewer overwhelm. Aider maintains a collaborative workflow with patches of 20-30 lines and rapid feedback cycles. For established codebases, standardizing specifications rather than reviewing raw code scales code ownership effectively.

**03 / [SQL Is Solved. Here's Where Chat-BI Still Breaks](https://juhache.substack.com/p/sql-is-solved-heres-where-chat-bi)** - Julien Hurault
Text-to-SQL generation works reliably-failures stem from upstream semantic issues. Testing revealed no SQL errors across 25 test cases, with all failures attributable to metric misinterpretation and business logic gaps.

**04 / [Agentic Annotated Bibliography](https://blog.philz.dev/blog/agentic-bibliography/)** - Philip
Agent systems reduce to LLMs executing in loops; unnecessary frameworks introduce overhead. Shell tools serve as the primary workhorse; isolation through git worktrees or VMs prevents cross-contamination.

**05 / [Apache Iggy's Migration to Thread-Per-Core Architecture](https://iggy.apache.org/blogs/2026/02/27/thread-per-core-io_uring/)** - Grzegorz Koszyk
Iggy transitioned from work-stealing schedulers to pinned threads with io_uring completion-based I/O. The system delivers sub-millisecond tail latencies at high concurrency while processing millions of messages per second on standard hardware.

**06 / [The Next Evolution of Delta - Catalog-Managed Tables](https://delta.io/blog/2026-02-02-delta-catalog-managed-tables/)** - Benjamin Mathew et al.
Delta 4.1 shifts authority from filesystem paths to catalog coordination, eliminating path-based discovery and reducing metadata latency from 100ms+. This aligns Delta and Iceberg on catalog-first approaches.

**07 / [2026 Agentic Coding Trends Report](https://resources.anthropic.com/hubfs/2026%20Agentic%20Coding%20Trends%20Report.pdf)** - Anthropic
Eight trends reshape software development: evolution from single agents to coordinated agent systems, introduction of long-running agents, shift from human oversight to intelligent collaboration, and expanded non-technical use cases.

**08 / [How Autoresearch Will Change Small Language Models Adoption](https://www.philschmid.de/autoresearch)** - Philipp Schmid
AI agents autonomously edit training code and conduct 5-minute experiments. Andrej Karpathy achieved 11% GPT-2 speedup in 2 days (~700 experiments). Users specify optimization targets in markdown; overnight hyperparameter searches execute without manual intervention.

**09 / [Your Data Agents Need Context](https://a16z.com/your-data-agents-need-context/)** - Jason Cui and Jennifer Li
Data agents fail without business context, unable to distinguish outdated semantic layers or navigate tribal knowledge. The bottleneck lies in context freshness rather than agent capability.

**10 / [Balancing Cost and Reliability for Spark on Kubernetes](https://www.notion.com/blog/balancing-cost-and-reliability-for-spark-on-kubernetes)** - Justin Lee
Notion's Spot Balancer maintains desired spot/on-demand instance ratios per job. Karpenter combined with MostAllocated scheduling achieves 60-90% cost reductions while maintaining reliability.
