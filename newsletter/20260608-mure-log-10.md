## Our feed

**01 / [I Built a (Very Small) Agent Swarm](https://roundup.getdbt.com/p/i-built-a-very-small-agent-swarm)** - Tristan Handy
Explores micro agent swarm architecture and lessons learned from implementation.

**02 / [Beyond the Semantic Layer: Building a Context Layer for the Agentic Era](https://www.kaelio.com/blog/building-a-context-layer-for-the-agentic-era)** - Simon Späti
Context layer development using [ktx](https://github.com/Kaelio/ktx).

**03 / [Routing Multiple Query Engines with Iceberg](https://lakeops.dev/blog/routing-multiple-query-engines-with-iceberg)** - Rob M
Query routing across Trino, Spark, DuckDB, Snowflake, Athena, and Flink on shared Iceberg tables.

**04 / [How Anthropic Enables Self-Service Data Analytics with Claude](https://claude.com/blog/how-anthropic-enables-self-service-data-analytics-with-claude)** - Anthropic
Strategies for maximizing Claude's self-serve business insights capabilities.

**05 / [LLM Research Papers: The 2026 List (January to May)](https://magazine.sebastianraschka.com/p/llm-research-papers-2026-part1)** - Sebastian Raschka
Curated LLM research papers from January to May 2026.

**06 / [TPC-H for Less Than a Cent: ClickHouse Cloud vs. Snowflake, Databricks, BigQuery, and Redshift](https://clickhouse.com/blog/tpc-h-clickhouse-cloud-vs-snowflake-databricks-bigquery-redshift)** - Tom Schreiber et al.
ClickHouse Cloud benchmark comparisons. [Public GitHub repository](https://github.com/ClickHouse/tpc-h-openhouse) with scripts and results.

**07 / [Writing Agent Skills for an Open Source Project: Lessons from DataFusion Python](https://datafusion.apache.org/blog/2026/05/28/writing-agent-skills/)** - Tim Saucer
Guidance on skill design, placement decisions, API evolution, and real-world evaluation.

**08 / [How OpenAI Built Its Data Agent](https://blog.bytebytego.com/p/how-openai-built-its-data-agent)** - Alex Xu with Emma Tang
OpenAI's data agent architecture and operational details.
