## Data Reads

**01 / [Python Was Built for Humans. AI Just Changed Everything](https://www.rilldata.com/blog/the-day-pythons-most-famous-developer-realized-agents-dont-care-about-readability)** — Michael Driscoll
Agents prioritize rapid feedback cycles over code readability. Go's instant compilation addresses Python's iteration bottleneck, enabling production systems in weeks instead of months.

**02 / [The Quest for One Million IOPS: Benchmarking Storage at LanceDB](https://lancedb.com/blog/one-million-iops)** — Weston Pace
LanceDB achieved 1.5M IOPS through I/O scheduler optimization and io_uring implementation. Single-read metrics poorly indicate random access performance characteristics.

**03 / [Vector Search Using Only Parquet and DataFusion](https://blog.xiangpeng.systems/posts/vector-search-with-parquet-datafusion/)** — Xiangpeng Hao
Aligning Parquet page sizes with embedding dimensions enables efficient random access. Adding a zero-copy IVF index yields "5.7x speedup at 96% recall" without specialized databases.

**04 / [Lance Table Format Explained Simply](https://tontinton.com/posts/lance/)** — Tony Solomonik
Lance represents an evolution beyond Iceberg/Delta, optimized for point lookups and schema modifications without data rewriting. Supports native indexing (BTree, inverted, HNSW) and multimodal data.

**05 / [Building an Agentic Memory System for GitHub Copilot](https://github.blog/ai-and-ml/github-copilot/building-an-agentic-memory-system-for-github-copilot/)** — Tiferet Gazit
Copilot stores memories with citations agents verify in real-time. Cross-agent learning improves pull request merge rates by 7% and review quality by 2%.

**06 / [Data Teams Should Become Context Teams](https://thenewaiorder.substack.com/p/data-teams-should-become-context)** — Claire Gouze
Context engineering integrates governance, ETL, and measurement practices. Analytics agents provide the ideal testing ground before broader implementation.

**07 / [Barefoot Data Platforms](https://davidgasquez.com/barefoot-data-platforms/)** — David Gasquez
Minimal infrastructure replacing orchestration frameworks: agents write boilerplate efficiently while humans maintain architecture. Effective for datasets under 200 assets.

**08 / [Inside OpenAI's In-House Data Agent](https://openai.com/index/inside-our-in-house-data-agent/)** — Bonnie Xu et al.
Kepler serves 3,500 employees across 600PB of data using GPT-5 and MCP. Six-layer context architecture includes metadata, usage patterns, codex analysis, memory, credentials, and business glossary.

**09 / [Announcing msgvault: Lightning Fast Private Email Archive](https://wesmckinney.com/blog/announcing-msgvault/)** — Wes McKinney
Local-first Gmail archiver synchronizes 2M emails with millisecond DuckDB query performance. Content-addressed deduplication provides superior retrieval versus Google's system. [msgvault.io](https://www.msgvault.io)

**10 / [The Semantic Layer Is Back. Here's What We're Doing About It](https://preset.io/blog/semantic-layer-is-back/)** — Maxime Beauchemin
Semantic layers address trust requirements for AI systems. Earlier iterations failed due to BI vendor lock-in; contemporary approaches integrate with dbt while avoiding SQL bottlenecks.
