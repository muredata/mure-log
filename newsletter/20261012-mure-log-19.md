Hey, welcome back!

It's benchmark season. StarTree reaches 125K QPS on open tables, ClickHouse claims better price-performance than Databricks, and DuckDB halves Spark's cost on Glue. Benchmarks are useful, but read them with care, since vendors often run their own. In this issue: DuckDB 2.0's faster S3 reads, vector search as SQL joins, grading agents by database state, more on Jev, Polars 2.0, Cloudflare Basin, Supabase acquiring Turso, a wave of IVM tools, and more.

## Our feed

**01 / [Beyond the Databricks and ClickHouse Benchmarks: From 12k to 125k QPS on Open Tables with StarTree](https://startree.ai/resources/beyond-databricks-and-clickhouse-125k-qps-on-open-tables/)** - Arunkumar Saravanan
StarTree against Databricks and ClickHouse.

**02 / [Cost-effective ETL with DuckDB and Amazon S3 Tables on AWS Glue](https://aws.amazon.com/blogs/big-data/cost-effective-etl-with-duckdb-and-amazon-s3-tables-on-aws-glue/)** - Bezuayehu Wate and Manjeet Chayel
DuckDB example on Glue. On Glue with the same configuration, DuckDB ran the sample workload in about half the time and at about half the cost of Spark.

**03 / [Why Databricks can't match ClickHouse Cloud for real-time analytics](https://clickhouse.com/blog/clickhouse-vs-databricks-real-time-performance-per-dollar)** - Tom Schreiber and Lionel Palacin
ClickHouse Cloud vs. Databricks on 113.2B streamed quotes: ClickHouse delivered 752× better performance per dollar.

**04 / [DuckDB 2.0 and S3 File Read Performance](https://performancede.substack.com/p/duckdb-20-and-s3-file-read-performance)** - Matt Martin
DuckDB 2.0 alpha read JSON files from S3 about 3× faster than 1.5.6.

**05 / [NEAREST BY Join: Scaling Vector Search in Databricks Runtime](https://www.databricks.com/blog/nearest-join-scaling-vector-search-databricks-runtime)** - Zero Qu et al.
Databricks' new NEAREST BY join runs batch vector search in SQL. With an index, 1M queries against 1B vectors finish in minutes.

**06 / [The Agent Said It Was Done. The Database Disagreed](https://huggingface.co/blog/microsoft/thinkingbox)** - Tuhin Kundu
Microsoft's ThinkingBox grades agents on what they leave in the database.
