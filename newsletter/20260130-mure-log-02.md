## Data Reads

**01 / [xBound: Join Size Lower Bounds](https://arxiv.org/html/2601.13117v1)** — Mihail Stoian et al.
Database optimizers frequently underestimate join cardinality. xBound addresses this through "provable lower bounds," correcting 17.5% of DuckDB underestimates and up to 36.1% in Fabric environments.

**02 / [Multimodal with Delta Lake](https://brokenco.de/2026/01/19/multimodal-delta-lake.html)** — R. Tyler Croy
Storing PDFs, images, and video in Delta Lake without re-encoding uses Parquet Anchors and Virtual Delta Tables, enabling "petabyte-scale data untouched while exposing structured schemas."

**03 / [Slides-to-Speech: Turn your presentations into narrated content with CocoIndex and LanceDB](https://cocoindex.io/blogs/slides-to-speech)** — Linghua Jin, Prashanth Rao
CocoIndex and LanceDB automate presentation conversion through speaker note extraction, narration synthesis, and semantic search storage with auto-refresh capabilities.

**04 / [Scaling PostgreSQL to power 800 million ChatGPT users](https://openai.com/index/scaling-postgresql/)** — Bohan Zhang
PostgreSQL serves 800 million ChatGPT users via "single-primary + 50 read replicas" achieving five-nines availability and 10-50ms p99 latency through optimization and connection pooling.

**05 / [Claude meets JSON: Automating Databricks Dashboards](https://blog.cauchy.io/p/claude-meets-json-automating-databricks)** — Steven Kempers
Claude Code generates Databricks dashboards as JSON, reducing development from hours to "30-60 minutes" for complete multi-page prototypes using BAML subagents.

**06 / [From Human Ergonomics to Agent Ergonomics](https://wesmckinney.com/blog/agent-ergonomics/)** — Wes McKinney
LLM agents iterate dramatically faster than humans, making "Go/Rust dominate agent infrastructure" over Python due to performance considerations.

**07 / [AI Trends Reshaping Data Engineering in 2026](https://www.alibabacloud.com/blog/ai-trends-reshaping-data-engineering-in-2026_602816)** — Alibaba Cloud
Five emerging trends: data+AI infrastructure convergence, volume-to-freshness shift, unstructured data taming (representing 80% of enterprise knowledge), context emphasis, and agent-native infrastructure.

**08 / [Databricks Lakeflow vs Apache Airflow](https://dataengineeringcentral.substack.com/p/databricks-lakeflow-vs-apache-airflow)** — Daniel Beach
Lakeflow suits Databricks-exclusive workflows; Airflow dominates multi-cloud scenarios with "75% of users running ≤250 DAGs."

**09 / [How we use Apache DataFusion at Spice AI](https://spice.ai/blog/how-we-use-apache-datafusion-at-spice-ai)** — Phillip LeBlanc
DataFusion functions as a programmable query compiler supporting 20+ custom connectors, aggregate pushdown, and async UDFs for inline inference.

**10 / [How do you vibe-engineer?](https://juhache.substack.com/p/how-do-you-vibe-engineer)** — Julien Hurault
Effective agent development requires disciplined planning, aggressive simplification, and multi-model loops with "YAML-based orchestration as 2026 standard."
