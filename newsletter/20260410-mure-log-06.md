## Data Reads

**01 / [Beyond ETL: The Case for Context](https://agentblueprint.substack.com/p/beyond-etl-the-case-for-context)** — Michel Tricot
Movement solved; meaning remains unsolved. The ECL framework repositions focus from processing to semantic clarity. AI amplifies inadequate context; agents work with buried definitions. "Context Store materializes versioned, queryable semantic definitions—same pattern as materialized views, just for agents."

**02 / [Agent Skills: Disseminating Expertise](https://roundup.getdbt.com/p/agent-skills-disseminating-expertise)** — Tristan Handy
Expertise encodes as markdown; agents dynamically load it. "CLI agents beat MCP by 10–32x on token cost by avoiding unused tool schemas." Package skills alongside distributions to embed best practices.

**03 / [Lower Your Warehouse Costs via DuckDB Transpilation](https://maxhalford.github.io/blog/warehouse-cost-reduction-quack-mode/)** — Max Halford
Execute queries locally via transpilation; only warehouse dependencies remain remote. "Quack mode" evaluates dependencies, executes locally via DuckLake on object storage. Iceberg enables cost-free hybrid execution.

**04 / [A Sufficiently Detailed Spec Is Code](https://haskellforall.com/2026/03/a-sufficiently-detailed-spec-is-code)** — Gabriella Gonzalez
Specifications claiming superiority over code are often pseudocode disguised. Real precision requires code-like structures. Testing with Claude exposed silent failures. "Specs aren't time-saving; garbage in, garbage out."

**05 / [Why Real-Time Data Sync Is Still Unsolved](https://x.com/odysseus0z/status/2032570785341296993)** — George
Change detection works; routing changes to affected queries doesn't. "Databases don't track who's watching." Thirteen years of Google attempts failed because integrated stacks don't exist. Reactivity requires deliberate co-design.

**06 / [State of Context Engineering in 2026](https://www.newsletter.swirlai.com/p/state-of-context-engineering-in-2026)** — Aurimas Griciūnas
Five patterns: progressive disclosure, compression, routing, agentic retrieval, tool management. Applying all five controls what enters systems and governs retention.

**07 / [AI and the Mixed-Consistency Future](https://jhellerstein.github.io/blog/ai-mixed-consistency/)** — Joe Hellerstein
Industry adopts markdown; reads tolerate disorder, writes break. "Agentic state needs mixed-consistency: some coordination-free, some serializable." Concurrency bridges to approximation mathematics.

**08 / [Claude Code Isn't Going to Replace Data Engineers (Yet)](https://rmoff.net/2026/03/11/claude-code-isnt-going-to-replace-data-engineers-yet/)** — Robin Moffatt
Built production-ready dbt structure with tests but silently dropped 73% of source records. "Real value: DE + AI > DE." Iteration excels; autonomous delivery fails silently.
