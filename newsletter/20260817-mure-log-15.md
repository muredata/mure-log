Agentic development is becoming standard for data teams. This issue covers Claude Code for data engineering, BigQuery improvements, Iceberg's new Variant type, and how open models are eliminating model moats, forcing competition through lock-in and specialization instead.

## Our feed

**01 / [Claude Code for Data Engineering](https://www.anthropic.com/webinars/claude-code-for-data-engineering)** - Kevin Lou et al.
Data engineering using Claude. 40-minute video.

**02 / [Agentic Future Ready With BigQuery: Continually Improving Price-Performance, Zero Effort](https://cloud.google.com/blog/products/data-analytics/bigquery-performance-optimizations)** - Joe Yong and Manan Goel
Enhanced vectorization, symmetric multi-processing (SMP), and TPC-DS performance results.

**03 / [How Kenn is doing Agentic Engineering](https://wesmckinney.com/blog/agentic-engineering-aug-2026/)** - Wes McKinney
Building in the agentic era with superpowers and roborev features.

**04 / [How to get started with agentic development for business intelligence and analytics](https://tabulareditor.com/blog/how-to-get-started-with-agentic-development-for-business-intelligence)** - Kurt Buhler
Core pillars for agentic BI and analytics development.

**05 / [Context Engineering is a Data Problem](https://davidgasquez.com/context-engineering-is-a-data-problem)** - David Gasquez
Context engineering as data engineering. Related: ["From analytics engineer to context engineer"](https://www.getdbt.com/blog/from-analytics-engineer-to-context-engineer) by Britton Stamper.

**06 / [This is why we can't have nice things](https://benn.substack.com/p/this-is-why-we-cant-have-nice-things)** - Benn Stancil
Open models replicate frontier capabilities overnight (Kimi K3 vs. GPT/Claude), eliminating model moats and forcing differentiation through enterprise lock-in, specialization, or expertise.

**07 / [Semi-Structured Data in Apache Iceberg: Meet the Variant Type](https://iceberg.apache.org/blog/variant-in-apache-iceberg/)** - Neelesh Salian
New Variant type for handling semi-structured data in Apache Iceberg.
