## Data Reads

**01 / [A Diary of a Data Engineer](https://www.ssp.sh/blog/diary-of-a-data-engineer/)** - Simon Späti
"Tools change, fundamentals don't. Learn data modeling deeply, understand how data flows." Excel isn't problematic-business needs drive requirements. When work succeeds, you remain unseen. When failures occur, you face intense scrutiny.

**02 / [Databases in 2025: A Year in Review](https://www.cs.cmu.edu/~pavlo/blog/2026/01/2025-databases-retrospective.html)** - Andy Pavlo
PostgreSQL continues expanding dominance. Databricks invested $1B in Neon; Snowflake acquired CrunchyData for $250M. MCP became standardized for AI-to-database connections. MongoDB pursued legal action against FerretDB. File format competition intensified with five new Parquet alternatives.

**03 / [10 Predictions for Data Infrastructure in 2026](https://columnar.tech/blog/2026-predictions/)** - Ian Cook
"Arrow approaches its 10th anniversary as ubiquitous infrastructure but faces funding strain." ADBC emerges as connectivity layer for columnar data. Iceberg advanced beyond speculation into operational deployment. Multi-engine architectures achieve mainstream adoption. Interoperability engineering delivers highest strategic value.

**04 / [DEW - The Year in Review 2025](https://www.dataengineeringweekly.com/p/dew-the-year-in-review-2025)** - Ananth Packkildurai
Data engineering evolved from pipeline management toward cognitive infrastructure. "MCP became 'USB-C for Agents.'" The constraint shifted from model capacity toward meaning management. "The 'Big Data' era ended; the 'Context Era' began."

**05 / [Data Engineering in 2026: What Changes?](https://gradientflow.substack.com/p/data-engineering-for-machine-users)** - Ben Lorica
Dual pressures: expanded automation with agents performing substantive work, and increased scrutiny where "close enough" fails. Databricks reports 80%+ of new databases launched by agents. Fragmentation complexity undermines agentic dependability.

**06 / [From ETL to Autonomy: Data Engineering in 2026](https://thenewstack.io/from-etl-to-autonomy-data-engineering-in-2026/)** - Chris Child
Data engineers transition from implementers to strategists. "Open formats like Iceberg will be embraced by C-suites as the AI foundation-eliminating vendor lock-in." The metadata layer becomes critical control infrastructure.

**07 / [Explore public datasets with Apache Iceberg & BigLake](https://opensource.googleblog.com/2026/01/explore-public-datasets-with-apache-iceberg-and-biglake.html)** - Talat Uyarer et al.
Quality public datasets accessible via Iceberg REST Catalog on BigLake. Engine-agnostic approach: Spark, Trino, Flink, BigQuery-users supply compute; platform provides storage and catalog. V3 specification test datasets launching soon.

**08 / [Keep Your Data Fresh with CocoIndex and LanceDB](https://lancedb.com/blog/keep-your-data-fresh-with-cocoindex-and-lancedb/)** - Prashanth Rao et al.
CocoIndex automatically synchronizes source and target through incremental transformations. Combined with LanceDB-supporting multimodal vector storage-enables live semantic search without manual updates.

**09 / [How Slack achieved operational excellence for Spark on Amazon EMR using generative AI](https://aws.amazon.com/blogs/big-data/how-slack-achieved-operational-excellence-for-spark-on-amazon-emr-using-generative-ai/)** - Avijit Goswami et al.
Slack developed monitoring capturing 40+ Spark metrics, processing through Kafka and Iceberg, leveraging Bedrock for AI-driven optimization. Outcomes: 30-50% expense reductions, 40-60% accelerated jobs. Metrics exposed via internal MCP server for Cursor/Claude Code integration.
