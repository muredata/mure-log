AI agents can generate queries, dashboards, pipelines, and analyses, but they cannot yet generate trust in answers or assume responsibility. People remain the differentiator - the moat as more agents touch data systems. This issue explores semantic layers rebuilt as markdown, why self-service expands rather than replaces data teams, next-generation analytics tools resembling files, and dbt on Fabric Spark achieving 50%+ performance gains.

## Our feed

**01 / [The Shape and Feel of the Post-AI Data Stack](https://www.iandmacomber.com/blog/post-ai-data-stack)** - Ian Macomber
Great read. Post-AI, consensus is something you engineer. The job of the post-AI data scientist is to make sure the meaning survives the edit.

**02 / [Are Data Teams Cooked?](https://joereis.substack.com/p/are-data-teams-cooked)** - Joe Reis
Instead of killing off data teams, self-service expands the scope of opportunities. Related: ["From Data Engineer To ?? Engineer"](https://juhache.substack.com/p/from-data-engineer-to-engineer) by Julien Hurault.

**03 / [The Semantic Layer Nobody Maintains](https://blog.angellist.com/the-semantic-layer-nobody-maintains)** - Beau Rothrock
AngelList replaced the semantic layer with self-generating knowledge and skills: plain markdown that an AI agent reads, and GitHub Actions keep current.

**04 / [Context, Semantics, and Ontology: A Primer for the Agentic Era](https://motherduck.com/blog/context-layer-vs-semantic-layer-ontology/)** - Simon Späti
Semantic layer, context layer, ontology, knowledge graph? Great write up.

**05 / [How to find insights](https://benn.substack.com/p/how-to-find-insights)** - Benn Stancil
The next generation of analytics tools might look more like a file than a fancy SaaS product + Excel of course. Example: DuckDB + coding agent.

**06 / [AI-Powered Data Warehouses: Architectural Lessons for Every AI Product](https://x.com/JoshARosen/status/2095488762532745712)** - Josh Rosen
The data stack is a preview of AI architecture.

**07 / [dbt with Fabric Spark how to get 50%+ faster execution](https://www.rakirahman.me/dbt-nee-perf/)** - Raki Rahman
dbt + Fabric Spark + Native Execution Engine (NEE) performance gain.
